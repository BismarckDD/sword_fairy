# 游戏内菜单与统一确认键

## 操作

- 地图中按 ESC 打开“状态、技能、物品、系统”，上下选择，回车或空格确认。
- 状态、技能、物品沿用原有角色状态、技能和物品界面及业务逻辑。关闭后重新显示主菜单，并保留选中项。
- 系统包括“音乐 开/关、音效 开/关、读档、存档、退出游戏”。音乐与音效沿用原来的设备配置和开关逻辑，切换后停留在系统菜单。
- 系统按 ESC 返回主菜单，主菜单按 ESC 返回游戏。存档完成或取消、读档取消均返回系统；读档成功直接恢复游戏。
- 退出游戏需确认，默认选中取消。确认框同样使用原游戏菜单。
- 地图中回车和空格均执行原来的调查/对话动作，回车不再打开旧的三项菜单。物品、技能、战斗行动菜单、选项和对话快速显示均支持这两种确认键。
- 窗口忽略回车、空格、ESC 的系统自动重复按下消息，避免长按跨层连续确认。

## 实现

主菜单与系统菜单复用 `jx_action_menu` 的背景捕获、背景映射、72 像素宽边框、原字体、行距、选择颜色和音效。新增 `jx_menu_select` 仅返回选择，不使用共用回调表；在进入子界面前恢复背景，返回后按保留的选中项重新绘制菜单。这避免父子层共享背景缓存和回调表造成覆盖。

主循环仍使用原 142 字节工作区：文字在 +2..81，事件在 +82..89，文字指针在 +90..109，选择器工作区在 +108..141（有效事件从 +110 开始）。各层按需重建文字；不递归叠放共用缓存。

99 档浏览器改为直接在原 VGA 画面绘制，不再创建 Windows 弹窗。字体调用原游戏绘字函数，边框和高亮沿用原色号，背景沿用原映射表。160×100 真彩色预览映射至当前调色板，不修改游戏调色板。关闭后恢复原画面及绘制页。

存档格式、配套预览及旧档兼容规则见 [存档界面说明](SAVE_BROWSER.md)。

## 验证

- 严格编译通过。
- `--menu-system-probe` 使用实际资源和游戏绘制，验证四项主菜单、系统开关、退出默认取消、状态/技能/物品返回、两种确认键和浏览器末页取消，并导出各阶段画面供视觉检查。
- `--main-menu-probe` 改用新菜单回归路径，保留其旧档初始化。
- `tests/native_save_browser.c` 在全新隔离目录验证原格式恢复、01/10/11/99 档、旧档回退、异常档、预览校验、翻页、两种确认键、默认不覆盖、主动覆盖和背景恢复；不写入玩家目录。
- `tests/menu_navigation.c` 验证地图双键交互、存读档取消返回、读档成功关闭菜单、退出默认取消与主动确认，并检查原 142 字节工作区边界。
- `tests/native_window_timing.c` 增加确认键自动重复消息验证，并保留窗口计时和调色板刷新回归。
- `--load-probe` 验证真实旧档读取及 64 帧世界调度。

已检查实际资源绘制的菜单、状态、技能、物品和存档界面截图。完整剧情与全部战斗、全部角色组合仍需进一步实际游玩验证；较长自动路线若依赖旧回车菜单操作，需要随菜单操作路径更新，不能沿用此前整游戏验证结论。
