# 四倍素材与 1280×800 显示

## 当前功能

地图、行走人物与战斗动画已增加 21,482 张保留原造型的 AI 超分素材，独立安装在 `hd/superres/`，与下列 416 张基础素材同时加载。范围、验证及卡顿修复见 [AI 超分说明](AI_ART_REDRAW.md)。早期手绘候选未启用。

- 游戏主画面为 320×200，高清输出为 1280×800，两轴各放大四倍（8:5），不做 4:3 拉伸。
- 本地独立素材目录为 `runtime/game/hd/`。本次生成 416 张四倍图片：66 张静态 IMG 帧、350 张 FACE.INF 头像。全屏图为 1280×800，头像为 240×280，其余局部图片按原尺寸乘四。
- 默认素材采用原像素整数四倍放大，保留原字体笔画。当前另已导入用户重绘的 283 张素材（255 张头像、20 张战斗背景、8 张 SHADE 图），覆盖对应的默认图片；其余素材逐像素放大。
- 游戏在原图绘制时识别原索引像素，关联外部 BMP；在高清缓冲区合成。外部文件缺失、损坏或尺寸不符时，使用原画面的逐像素四倍显示。
- 地图图块、339 套行走人物及 104 个战斗动画已由独立超分包接入；字库仍保留原像素整数四倍显示。原始资源缺失的条目另列异常，不据此宣称全剧情人工验收完成。
- 原始 640×480 特殊界面仍按 4:3 显示，在 1280×800 窗口内保留左右黑边。

## 使用

直接运行 `runtime/game/启动游戏.exe`；启动器调用的程序仍是 `main_decompiled/build/jx_native.exe`，更新的是这个内部程序。

F8 切换高清合成与原像素显示，游戏逻辑继续运行。关闭游戏后将 `hd` 文件夹改名，即可禁用素材包并恢复原 960×600 默认窗口。运行中修改图片后需重启游戏。

```powershell
./tools/build-hd-pack.ps1
./scripts/build.ps1 -Target Game
./scripts/test-hd.ps1
```

可向构建和测试脚本传 `-Zig` 指定编译器。素材生成工具需要 PowerShell 自带的 C# 编译支持，不依赖 Python、网络或额外图像软件。首次准备运行目录后，再运行素材生成工具。重复生成会保留已有 BMP，避免覆盖人工编辑，但会重建参考数据和清单；原游戏版本须保持匹配。

## 素材目录

```text
hd/
  README.md
  manifest.tsv
  images/BEGIN_IMG_000.bmp
  images/FACE_INF_000.bmp
  references/BEGIN_IMG_000.idx
  references/FACE_INF_000.idx
```

`images/` 中的文件可继续人工重绘。运行格式为无压缩 32 位 BMP（40 字节 BITMAPINFOHEADER、BI_RGB），允许正向或倒序行；尺寸必须恰好为原图宽高的四倍。保留文件名。原图中的透明色索引仍负责遮罩，BMP 的 alpha 不参与合成，因此暂不支持超出原轮廓的半透明发丝、光晕或新遮挡。

`references/` 包含原调色板和原索引图，仅供匹配、透明掩码与调色板变换。不要编辑。清单采用无 BOM UTF-8，前五列由制表符分隔：资源名、原宽、原高、参考路径、BMP 路径。可选第六列 `truecolor` 表示保留重绘图的 RGB，仅随整体亮度淡入淡出；省略时按原像素索引处理调色板。路径相对于 hd，禁止绝对路径与 `..`。重新生成素材包会保留现有 BMP 及其颜色策略。

匹配采用索引图尺寸、哈希和逐字节比较。支持同宽图片的顶部裁剪；其他未识别裁剪回退运行时增强。完全相同的原像素会优先使用清单中首个匹配项，不根据原文件名区分相同像素。

## 渲染与兼容性

`native_hd.c` 保存四个 VGA 平面的高清来源标记。普通像素写入清除标记，显存 latch 复制保留标记；常规矩形截图和恢复可保存标记，最多缓存最近 12 个截图。字体、人物和特效覆盖在背景上时，不会被整张高清背景重新盖住。未接入的平面截图或复杂内存变换允许回退原像素增强。

普通素材按原像素对应的当前调色板调整高清颜色。`truecolor` 素材依据原图非透明像素的调色板总亮度计算统一淡入淡出比例，避免旧色表给新图染色；不逐索引重现调色板换色。高分彩图独立分配，不进入原 16 位缓冲区，不改变碰撞、剧情坐标、动作帧时长或存档格式。最多缓存 8 张解码后的 BMP；未变化画面直接复用上一帧。存档浏览器暂用原绘制结果，避免直接显存写入与高清标记冲突。
