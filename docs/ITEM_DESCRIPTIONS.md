# 物品效果说明

物品菜单左侧完整图标下方显示白字说明，直接保留原红色底纹，无黑底或额外边框，随选中位置更新。平时和战斗共用该界面，保留原图标、双列列表、数量和物品使用规则。

说明直接读取 THING.DAT 加载后的 28 字节物品记录，并按照实际使用代码解释：

| 字段偏移 | 药品效果 |
| --- | --- |
| 0x0E | 恢复生命 |
| 0x12 | 恢复内力 |
| 0x10 | 增加生命上限 |
| 0x14 | 增加内力上限 |
| 0x16 | 提升攻击 |
| 0x18 | 提升防御 |

恢复生命/内力不超过使用后的上限。战斗中药品作用于当前行动角色，平时沿用原来的对象选择。说明不把上限增加误写为当前值恢复，也不凭名称推测解毒、复活等未经代码确认的效果。

武器在平时显示装备攻防，在战斗物品菜单中显示投掷攻击与伤害基数；暗器显示伤害基数和消耗提示；剧情物品显示用途类别及战斗中无法使用的提示。伤害基数与实际最终伤害区分，保留原来的战斗计算。

现有物品的说明最多四行，从画面 y=132 开始，完整避开物品图案与装饰边框；扩展数据仍支持最多七行。每次先恢复原背景再绘制，避免从长说明切换到短说明或空档时残留文字。只读取物品效果，不改变血量、内力、属性或物品数量。

验证：严格构建及 `tests/item_description.c` 通过，覆盖字段对应、最大行数、切换清除、物品类别与查看不消耗；`--item-description-probe` 使用真实资源浏览药品、上限提升、属性提升、暗器和剧情物品，导出截图供视觉检查。检查过真实蛇胆酒、人参、药王金方和孙子兵法的显示结果。
